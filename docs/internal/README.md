# Internal notes

Plans, audits and design notes from building Circles. They are kept for history and for people working on the code. They are not a guide to using the app: that is in [docs/](../README.md).

These files were written when they sat directly under `docs/`, so a path in them such as `docs/hardening.md`, `docs/phases/...` or `docs/composers/...` now lives under `docs/internal/`. Some describe what a phase planned, and a later change may have replaced it. Where that matters the file says so at the top.

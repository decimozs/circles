# Documentation

The user guide is a website, built with [Fumadocs](https://www.fumadocs.dev) and hosted on Vercel. Its pages are
in [`apps/docs/content/docs/`](../apps/docs/content/docs), and the site's address is in the repository's README.

To read or write it on your Mac: `pnpm --filter @circles/docs dev`, then open <http://localhost:3000>.

This folder keeps what is for people working on Circles, not for people using it:

- [`internal/`](internal): the plans, the audits, the threat model and the release checklist.

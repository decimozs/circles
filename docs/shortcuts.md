# Keyboard shortcuts

Press Cmd+/ in the app to see the list. Cmd means the Command key.

| Shortcut | What it does |
|---|---|
| Cmd+K | Search: workspaces, projects, actions and settings |
| Cmd+N | Create workspace |
| Cmd+Option+A | Add project |
| Cmd+, | Open settings |
| Cmd+/ | Show the shortcuts |
| Cmd+[ and Cmd+] | Go back and go forward |
| Cmd+B | Show or hide the left sidebar |
| Cmd+Option+B | Show or hide the right sidebar |
| Cmd+. | Zen mode |
| Cmd+Option+T | Switch the theme |
| Cmd+Shift+D | Open or close the diff viewer |
| Cmd+Shift+P | Create a pull request |
| Cmd+R | Run the workspace's run script |
| Cmd+Shift+R | Stop the run script |
| Cmd+T | New terminal |
| Cmd+Shift+M | Maximize the terminal |
| Cmd+Shift+. | Stop all Composers |

Every action in the search (Cmd+K) shows its shortcut when it has one.

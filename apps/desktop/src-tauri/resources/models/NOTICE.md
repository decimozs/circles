# Model notice

Circles includes a small language model to name chats and suggest messages. It runs on this Mac
only. Nothing is sent anywhere.

- **Model:** SmolLM2-360M-Instruct, by Hugging Face (HuggingFaceTB).
- **Licence:** Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0
- **Source:** https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct
- **Format:** GGUF, quantised to Q4_K_M by bartowski,
  https://huggingface.co/bartowski/SmolLM2-360M-Instruct-GGUF
- **Run with:** llama.cpp (MIT licence), https://github.com/ggml-org/llama.cpp
